# Loja de Tecnologia

Este projeto é uma página web simples desenvolvida com HTML, CSS e JavaScript. A ideia foi criar uma página de apresentação para uma loja de tecnologia, com textos, imagem, lista de produtos e um botão interativo.

## Qual é a função do HTML na página desenvolvida?
A função do HTML é estruturar o conteúdo da página. Ele organiza os elementos como título, parágrafos, imagem, lista e botão, definindo a base visual e semântica da página.

## Onde você utilizou CSS e quais alterações ele realizou?
O CSS foi usado no arquivo `style.css` para mudar a aparência da página. Ele alterou a cor de fundo, definiu a fonte, centralizou o conteúdo, estilizou o título, ajustou a imagem, personalizou a lista e deu um visual mais bonito ao botão. Também foi usado para esconder e mostrar a mensagem de promoção.

## Onde você utilizou JavaScript e o que acontece quando ele é executado?
O JavaScript foi usado no arquivo `script.js` para criar interatividade. Quando o usuário clica no botão, o código verifica se a mensagem está escondida. Se estiver, ele mostra a promoção; se já estiver visível, ele esconde novamente. Isso torna a página dinâmica e mais interessante.

## Qual é a principal diferença entre CSS e JavaScript?
A principal diferença é que o CSS cuida da aparência e do estilo, como cores, tamanhos, posições e margens. Já o JavaScript cuida da interatividade e da lógica da página, como eventos, ações e mudanças em tempo real quando o usuário clica ou interage.

## Como abrir o projeto?
1. Baixe os arquivos `index.html`, `style.css` e `script.js`.
2. Coloque os três arquivos na mesma pasta.
3. Abra o arquivo `index.html` em um navegador.
